# 0.19.0-alpha.2

## Added

- ACP v1 stdio Agent Server as FreeSeek's third first-class host surface.
- `freeseek acp` unified command and `freeseek-acp` standalone bin.
- ACP lifecycle: `initialize`, `session/new`, `session/prompt`, `session/cancel`, `session/list`, `session/resume`, `session/close`.
- Bidirectional ACP client callbacks for `session/update` and `session/request_permission`.
- Durable ACP session metadata alongside the existing EventLog; session list/resume/close reuse persisted FreeSeek history.
- Per-session MCP runtimes, allowing ACP sessions to own independent stdio MCP connections.
- Shared standalone Provider adapter for CLI and ACP hosts.

## Changed

- MCP execution can use the `McpManager` carried by the current ToolContext instead of being forced through the process-global VS Code-compatible manager.
- ToolRuntime permission correlation now carries tool-call IDs through ACP reverse permission requests.
- ACP MCP metadata persists server names only; command, env and secret values remain client-owned and must be re-supplied on resume.
- ACP stdio MCP commands may be PATH-resolved (`node`, `npx`, etc.) rather than requiring absolute executable paths.

## Fixed

- ACP unknown/inactive sessions now use standard JSON-RPC invalid-params semantics instead of colliding custom `-32000` codes.
- Busy sessions use standard invalid-request semantics instead of a custom reserved-range code.
- Invalid `session/list` cursors return invalid-params rather than internal-error.
- Generic `$/cancel_request` notifications are ignored cleanly; session cancellation remains `session/cancel`.
- Removed a duplicate JSON-RPC error write in the transport's handler-unavailable path.

## Validation status

- `npm run check`: 8/8 gates pass (export JSDoc remains advisory).
- `npm test`: 336/336 pass, 0 fail.
- In-memory ACP protocol E2E covers lifecycle, durable resume, permission, MCP and cancellation.
- Real child-process E2E covers both `freeseek-acp` and unified `freeseek acp`, with NDJSON-only stdout and a real Agent/provider turn.
